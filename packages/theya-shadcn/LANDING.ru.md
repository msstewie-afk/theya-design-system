# Как собирать лендинг из Theya

Правила для агентов и для людей. Блоки в Theya есть, а эта страница о том, какие из них выбирать. В проверке 21.11.2026 агент разложил hero PlateCovery по компонентам буквально («стадии → Stepper», «тарелки на дуге → колесо-карусель»), и результат вышел плоским и мелким. Когда он начал с готовой композиции, большая часть проблем ушла, хотя блоки остались те же.

Истории лежат в Storybook в разделе `Patterns: Landing/*`. Правила каждого UI-компонента (когда использовать, когда нет, анатомия, доступность) есть в `spec/components/<name>.json` и в `public/llms-full.txt`. У блоков лендинга правила лежат в репозитории Theya, в `src/components/blocks/landing/<name>.guidelines.tsx`, и показываются на странице Docs каждого блока в Storybook.

## 1. Начинать с композиции, а не с компонентов

Сначала открыть эти истории, взять самую близкую и поменять в ней содержимое. Пустую страницу с нуля не раскладывать.

| Композиция | История | Для чего |
|---|---|---|
| App, restrained | `Patterns: Landing/Recipes → App, restrained` | мобильное приложение, спокойный продукт |
| Landing page | `Patterns: Landing/Landing page → Bookmarks`, `→ Gradient` | SaaS-продукт от начала до конца |
| First screens | `Patterns: Landing/First screens` (шесть экранов) | презентационные первые экраны с сильной типографской идеей: wordmark, швейцарское бенто, мозаика, манифест, коллаж |
| Варианты Hero | `Patterns: Landing/Hero` | centered, split, inset, statement, wordmark, название + подзаголовок + пункты |

## 2. Первый экран

- **Заголовок — дисплейный.** `Hero titleSize="display"` (56 → 128 px), `layout="wordmark"` или `"statement"`. Размеры heading — для секций ниже. Первый экран с заголовком размера секции читается как страница внутри приложения.
- **Если заголовок — название продукта,** к нему нужны `subtitle` (одна крупная строка о том, что продукт делает) и 2–4 `points`. Каждый пункт начинается с главного жирным.
- **Шрифт темы.** `titleFont="theme"` (по умолчанию) — шрифт заголовков темы, с засечками или без: в ember это Playfair Display. `display-serif` — EB Garamond из Theya при любой теме, только если он нужен сознательно.
- **Одно главное действие**, максимум ещё одно. На телефоне кнопки встают столбиком на всю ширину.
- **На ярком фоне текст тёмный.** Контраст надо мерить: белый на насыщенном оранжевом даёт около 2,7 : 1, этого мало.
- **Один h1** на страницу — у hero.
- **Стикер не закрывает слова на телефоне.** До 640 px `Sticker` стоит под заголовком; от 640 px может заходить на край буквы, но не на целое слово. Один на экран.

## 3. Какой блок для какой задачи

| Задача | Блок |
|---|---|
| Логотипы клиентов или прессы | `LogoStrip` (статично или бегущей строкой) |
| 3–6 возможностей | `FeatureCard` сеткой; `BentoGrid`, если вес разный |
| Одна возможность с картинкой | `FeatureSplit` |
| Возможности, где картинка меняется при выборе | `FeatureShowcase` |
| Шаги, «как это работает» | `StickySteps` |
| Цифры | `StatsRow`, `StatCard`, `CountUp` |
| Отзывы | `QuoteCard`, `TestimonialCase`; стена отзывов — `MarqueeColumns` |
| До и после | `BeforeAfter` |
| Строка-манифест, которая проявляется при прокрутке | `ScrollHighlight` |
| Тарифы и цены | `PricingSection` (внутри продукта — `PlanComparison`) |
| С какими сервисами работает | `IntegrationsSection` (сетка с фильтром или хаб) |
| Свежие статьи | `BlogTeaser` |
| Подписка на рассылку | `SiteFooter newsletter` |
| Вопросы | `FaqSection` |
| Финальный призыв | `CtaBand`, для цветной полосы — внутри `SectionPanel` |
| Цветная или градиентная полоса | `SectionPanel tone="primary"` или `tone="gradient"` (dusk, lagoon, ochre) |
| Продукт как настоящие карточки интерфейса поверх фона | `ProductCollage` + `CollageItem` |
| Экран приложения или веб-приложение в рамке | `DeviceFrame type="phone" \| "browser"` |
| Скачать мобильное приложение | `StoreButtons` (один магазин по устройству; официальные значки через `badges` перед запуском) |
| Одно игривое действие поверх заголовка или картинки | `Sticker` (с наклоном, пастельный, прямые углы; `asChild` для ссылки) |
| Переключить стадии, тарифы, режимы | `Tabs variant="chips"`, если у каждого выбора своя панель (хоть одна строка); `ToggleGroup`, если меняется только картинка |
| Одна картинка, которая меняется на месте | `ArcStage` (спокойное движение по дуге, для hero) или `Carousel` с одним слайдом в кадре |
| Витрина из 5–8 карточек с картинками | `OrbitCarousel` |

## 4. Не X для Y

- **`Stepper` — не переключатель.** Он показывает продвижение по процессу (форма, мастер). Для стадий, между которыми переключаются, нужен `Tabs variant="chips"`.
- **`OrbitCarousel` — не для одной сменяющейся картинки.** Его формам нужно от пяти карточек. Для одного блюда на стадию — `ArcStage`.
- **`Aurora` — не фирменный фон.** Он смешивает primary, info и success, и на оранжевой теме выходит бурый цвет. Для цветного фона — `SectionPanel tone="primary"` или `"gradient"`.
- **Скриншот — не картинка продукта,** если Theya может её нарисовать. Картинку надо собрать из компонентов Theya (пример — `BookmarksPreview`, `ProductCollage`), тогда она подхватит тему и тёмный режим.
- **`description` — не свалка.** Подзаголовок, фраза и список — это три разных слота.

## 5. Фоны, цвет, тени

- Градиентный фон задаёт профиль темы (поле `gradient` в `packages/tokens/src/profiles/*.json`): у dusk, lagoon и ochre он тёмный с белым текстом, у ember — яркий «хурма» с тёмным текстом (`gradient.ink`). На теме без градиента `tone="gradient"` даёт плоский primary.
- Первый экран с фоном до краёв окна: `SectionPanel tone="gradient" shape="bleed" padding="none"` вокруг `Hero` (история `Patterns: Landing/Hero → On Bright Gradient`). `image` ставит фото вместо сетки градиента.
- Картинка как фон (`SectionPanel image` + `imageGround` или Hero `backdrop={<ImageGround … />}`; примеры фонов — `public/asset-examples/backgrounds`, тон и место под текст описаны в `SOURCES.txt`). Если текст на ней не проходит, сначала подгоните фон, а не меняйте картинку: под белый текст — `tint="deep"` (primary с чёрным, тон в тон) и `contentTheme="dark"`, под обычный текст — `tint="surface"` или `opacity` ниже 100 (просвечивает заливка панели). Потом проверьте контраст глазами или по скриншоту: скан пропускает текст поверх картинок. `flip` (x / y / both) даёт из одной картинки четыре композиции; фото людей, текста и продуктов не отражать.
- На цветном фоне кнопки переключаются сами: при `data-surface="primary"`, а на градиенте залитая кнопка становится белой капсулой.
- Тени на цветном фоне — цветные (самый тёмный цвет фона), не серые.
- Пастельные акценты для стикеров, штампов и игривых карточек: `--color-bg-accent-{pink,cream,orange,yellow}`, текст на них — `--color-text-on-accent-*` (не ниже 4.5:1, одинаково в светлой и тёмной теме). Только на лендингах, не в экранах продукта; сырые примитивы для этого не брать.

## 6. Движение

- Длительности интерфейса заканчиваются на 450 мс. У лендингов есть ещё две: `--transition-duration-journey` (1600 мс, предмет едет по длинному пути, с кривой `--ease-travel`: `glide` для этого слишком резкая) и `--transition-duration-ambient` (16 с, один круг «дышащего» фона: `AmbientBlobs`). Для откликов интерфейса их не использовать.
- Если что-то движется само дольше 5 с, нужна видимая пауза (WCAG 2.2.2), а на скрытой вкладке движение останавливается.
- В режиме «меньше движения» всё просто появляется на месте. Ничего не ждёт анимации, чтобы стать читаемым.

## 7. Перед тем как сдать

- Экраны на 360, 768 и 1280 px, в светлой и тёмной теме.
- Доступность. В репозитории Theya — `node scripts/a11y-tree.mjs`, `a11y-auto.mjs` и `a11y-states.mjs` с `--only "<название истории>"` на каждой затронутой истории. В приложении — axe на странице в обеих темах и ручная проверка клавиатуры.
- Журнал отступлений: что пришлось собрать руками и какого блока, пропа или токена Theya не хватило. По этому журналу Theya и растёт.
