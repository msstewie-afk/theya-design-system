# Продуктовые профили и темы

Профиль перекрашивает Theya под продукт одним атрибутом — без правок компонентов:

```html
<html data-brand="lime">                    <!-- светлая -->
<html data-brand="lime" data-theme="dark">  <!-- тёмная -->
```

Без `data-brand` — обычная синяя Theya. В Storybook профиль переключается кнопкой **Brand** в тулбаре.

Профили лежат в `packages/tokens/src/profiles/<имя>.json` и бывают двух видов.

| Вид | Что меняет | Готовые |
|---|---|---|
| простой | только оттенок основного цвета | — (формат ниже, для быстрых проб) |
| полная тема | основной цвет, текст на нём, нейтральные и вторичные цвета, поверхности, текст и ссылки — отдельно для светлой и тёмной темы; шрифт и радиусы | `iris`, `lime` |

| Тема | Цвета | Шрифт | Радиусы |
|---|---|---|---|
| `iris` | фиолетовый primary `#743de4`, индиго-ссылки, холодные почти серые нейтрали, сине-чёрная тёмная тема | Onest | острые: поля 2px, остальное по той же пропорции (кнопки 3, карточки 3, диалоги 4) |
| `lime` | лаймовый primary `#9fe870` с тёмно-зелёным текстом, зеленоватые нейтрали, почти чёрная зелёная тёмная тема | Manrope | ×1.5, кнопки-пилюли, поля 12px |

## Простой профиль

```json
{ "hue": 300, "chroma": 1, "description": "Продукт X" }
```

- `hue` — оттенок в OKLCH, 0–360;
- `chroma` — множитель насыщенности (по умолчанию 1).

## Полная тема

```json
{
  "description": "…",
  "primary": "#9fe870",
  "onPrimary": "#163300",
  "neutral": { "hue": 140, "chroma": 0.1 },
  "light": { "tokens": { "text-text": "#0e0f0c", "bg-neutral-bg-neutral-subtle": "#ecefec" } },
  "dark":  { "tokens": { "bg-surface-bg-surface-base": "#121512", "text-text-link": "#9fe870" } },
  "accept": ["primary hue vs success"],
  "font": "Manrope",
  "radius": { "scale": 1.5, "button": "max", "field": "xl" }
}
```

| Поле | Что делает |
|---|---|
| `primary` | цвет основной заливки (кнопки, выбранный день, чекбокс), точно такой в обеих темах. Hover и pressed — он же, темнее на 0.05 и 0.10 по L. Можно переопределить для одной темы: `dark.primary` |
| `onPrimary` | текст и иконки на этой заливке. Если не указан — белый, когда он даёт 4.5:1, иначе самая тёмная ступень шкалы. Для светлой заливки (как у `lime`) обязательно тёмный |
| `neutral` | перекрашивает нейтральные шкалы (slate, gray, graphite и их прозрачные версии): `hue` — оттенок, `chroma` — множитель насыщенности (у Theya нейтрали лавандовые, 0.1–0.2 делает их почти серыми). От них зависят вторичные кнопки, бордеры, текст, тёмные поверхности |
| `light.tokens`, `dark.tokens` | точные значения отдельных семантических токенов (имя без `--color-`). Применяются последними, поэтому побеждают всё сгенерированное. Так задаются поверхности, цвет текста, ссылки — то, что у продукта своё |
| `accept` | сознательные отступления от проверок (см. ниже) — сборка их печатает, но не падает |
| `font` | шрифт темы вместо Geologica (для заголовков и текста). Шрифт должен быть подключён в `packages/tokens/fonts/fonts.css` — там уже есть Manrope и Onest; браузер скачивает его, только если тема включена. Начертания возвращаются к номинальным (400/500/600/700): у Theya они сдвинуты на −125, потому что Geologica выглядит жирнее |
| `radius.scale` | множитель шкалы радиусов sm…5xl, округляется до целых px (`max` остаётся пилюлей) |
| `radius.anchor` | вместо `scale`: одна ступень получает заданное значение, остальные масштабируются так же. `{ "lg": 2 }` — поля 2px, вся шкала ×⅓ (так у `iris`) |
| `radius.button`, `radius.field` | один радиус для всех размеров Button и для TextField + Select: шаг шкалы (`xl`, `max`) или px |

## Как строятся цвета (OKLCH)

Каждая шкала (основная и нейтральные) переводится в OKLCH. Светлота **L** каждой ступени остаётся как у Theya, меняются только оттенок **H** и насыщенность **C**. Цвета за пределами sRGB возвращаются в неё снижением насыщенности. Поэтому каждая ступень остаётся на своём месте шкалы, а контраст почти не меняется — в отличие от HSL, где «одинаковая» светлота у жёлтого и синего выглядит совсем по-разному.

- Основная шкала берёт оттенок из `primary`, насыщенность подстраивается так, чтобы ступень 500 совпала с ним. Из неё получаются ссылки, иконки, бордеры, тональные фоны.
- Все семантические токены, которые ссылаются на перекрашенные шкалы (светлые, тёмные и code-токены), получают новые значения. Примитивы (`--color-blue-*`, `--color-slate-*`…) тоже переопределяются — их напрямую используют несколько компонентов.

## Проверки при сборке

Сборка падает, если в какой-то теме:

- **контраст** упал ниже порога там, где у Theya он был выше:
  - 4.5:1 — текст (обычный, subtle, subtler, ссылки) на поверхностях и текст на основной заливке;
  - 3:1 — иконки, бордер primary и сама заливка относительно фона страницы;
- **оттенок** основного цвета ближе 20° к статусному (success, warning, danger, info). Иначе основная кнопка читается как статус: например, оранжевый профиль (60°) совпадает с тёмным warning (47°);
- в `tokens` указан несуществующий токен.

Отступление можно разрешить через `accept`. У `lime` их два, оба — свойство самого цвета:

- `primary hue vs success` — основной цвет зелёный, он в 18° от success;
- `light: bg-primary-bg-primary on bg-surface-bg-surface-base` — лаймовая заливка на белом 1.47:1. Кнопку определяет тёмный текст на ней (9.45:1), но включённый Switch или отмеченный Checkbox отличаются от выключенного в основном цветом. Это такое же принятое отступление, как focus ring в аудите WCAG.

## Ограничения

- `data-brand` ставится на `<html>`: shadcn-переменные (`--primary` и др.) вычисляются на корне, поэтому профиль на вложенном элементе их не перекрасит.
- Цвета графиков (`--color-bg-chart-*`) и статусные цвета профиль не меняет.
- Плотность тема не задаёт — это отдельный слой (`data-density`, см. DENSITY.ru.md), его можно сочетать с любой темой.
- Шрифт и радиусы, как и shadcn-переменные, работают при `data-brand` на `<html>`.
