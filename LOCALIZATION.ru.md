# Локализация встроенных строк

Компоненты Theya сами пишут часть текста: скрытые подписи для скринридеров («Close», «Clear date»), плейсхолдеры («Pick a date»), служебные слова («Copied», «Unlimited»), объявления для скринридеров. Этот текст берётся из словаря. Текст, который передаёт приложение, библиотека не трогает.

## В приложении

```tsx
import { TheyaLocaleProvider } from '@theya/shadcn/lib/i18n';
import { ruLocale } from '@theya/shadcn/lib/locale-ru';

<TheyaLocaleProvider {...ruLocale} syncDocument>
  <App />
</TheyaLocaleProvider>
```

- **Без провайдера** всё на английском.
- **`syncDocument`** — провайдер сам ставит `lang` (и `dir`, если он есть в бандле) на `<html>` и возвращает прежние значения при размонтировании. По `lang` скринридер выбирает голос: без него русские подписи читаются английским голосом. Включайте только у корневого провайдера — вложенный провайдер для одного виджета не должен переименовывать всю страницу.
- **Готовые словари:**

  | Язык | Импорт |
  |---|---|
  | English | `locale-en` (`en`, `enLocale`) |
  | русский | `locale-ru` |
  | Deutsch | `locale-de` |
  | العربية | `locale-ar` |
  | 中文 | `locale-zh` |

  Каждый бандл содержит: `locale` (тег для Intl), `messages`, `dateLocale` (date-fns, для календарей) и `dir`.
- **Направление текста (RTL).** Нужно в двух местах (`syncDocument` закрывает оба):
  - на странице: `<html dir={bundle.dir}>` — от него зеркалится вёрстка;
  - в провайдере: `<TheyaLocaleProvider {...arLocale}>` (бандл уже несёт `dir`) — от него Radix-компоненты, Carousel, Drawer и ProductTour узнают направление для клавиш и сторон.
  Подробнее — раздел «RTL» ниже.
- **Частичная замена.** Можно заменить одну строку, остальное возьмётся из английского:
  `<TheyaLocaleProvider locale="en-GB" messages={{ dialog: { close: 'Done' } }}>`.
- **Пропсы компонента сильнее словаря:** `dismissLabel`, `placeholder`, `copyLabel` и т. п.
- **Даты и числа** (DatePicker, DateRangePicker, Scheduler, Meter, Price, страны в PhoneField) форматируются по `locale` провайдера. Без провайдера — en-US.
- **Код вне React.** `undoToast()` и `toast.progress()` берут строки последнего отрисованного провайдера (`getTheyaMessages()`).

## В Storybook

В тулбаре есть переключатель **Language**: English, Русский, Deutsch, العربية (RTL), 中文, Pseudo.

- **Pseudo** удлиняет каждую встроенную строку примерно на 40% и добавляет акценты: `[Çlöšé ~~]`. Строка, которая осталась обычным английским, зашита в компонент мимо словаря. Обрезанная строка не переживёт перевода.
- **Deutsch** — длинные реальные слова.
- **中文** — короткий текст и системный шрифт: в Geologica нет иероглифов.
- **العربية** включает `dir="rtl"`.

## Как добавить строку

1. Добавьте ключ в `packages/theya-shadcn/src/lib/locale-en.ts`, в пространство имён компонента.
2. В компоненте возьмите строку из словаря:
   ```ts
   const { t } = useTheyaI18n();
   if (clearLabel === undefined) clearLabel = t.datePicker.clear;
   ```
   Значение по умолчанию пишите не в параметрах, а так, как в примере выше. Тогда проп по-прежнему может его переопределить.
3. Добавьте перевод в каждый `locale-*.ts`. Без перевода не пройдёт `tsc`: словари типизированы по английскому.
4. Запустите `pnpm api`. Значения по умолчанию попадут в спецификацию и отчёт API с пометкой `(localized: …)`.

Переводы на немецкий, арабский и китайский сделаны без носителя языка. Перед продуктом на этих языках их стоит проверить.

## RTL

Theya зеркалится под письмо справа налево (арабский, иврит, фарси).

Что сделано:

- **Логические отступы и стороны.** Компоненты используют `ms/me`, `ps/pe`, `start/end`, `text-start/end`, `border-s/e`, `rounded-s/e` вместо `ml/mr`, `left/right` и т. п. — в RTL они сами меняются местами. `pnpm api:check` падает на физических (`node scripts/check-rtl.mjs --fix` переводит их автоматически). Исключения: центрирование `left-1/2` (оно симметрично) и `drawer.tsx` (vaul знает только физические стороны).
- **Направленные иконки** (стрелки «назад/вперёд», шевроны, отмена/повтор, внешняя ссылка) отражаются через `rtl:-scale-x-100`.
- **Переключатели и шкалы:** ползунок Switch, заполнение Progress, подписи Stepper идут от начала строки; Slider, Tabs, RadioGroup, меню и подменю — через Radix `DirectionProvider`, который ставит `TheyaLocaleProvider`.
- **Carousel:** первый слайд справа, «вперёд» листает влево, стрелки клавиатуры следуют направлению.
- **Drawer:** `direction="start" | "end"` — сторона по направлению чтения (в RTL `end` открывается слева). Боковое меню Sidebar на телефоне, фильтры каталога и мега-меню используют их.
- **ProductTour:** ← в RTL — следующий шаг.
- **Что остаётся LTR:** код (CodeBlock, CodeEditor, DiffViewer, Terminal) и сочетания клавиш (Kbd: `⌘K`, а не `K⌘`).

Проверено глазами в Storybook (Language → العربية): Pagination, Breadcrumb, Switch, Progress, Tabs, Slider, Stepper, Calendar, DropdownMenu, Carousel, WorkspaceLayout, DataTable. Автоматического визуального прогона в RTL нет: play-тесты ищут элементы по английским подписям.

Не сделано: вычитка арабского (и немецкого, китайского) словаря носителем языка; графики (Recharts) остаются LTR.
