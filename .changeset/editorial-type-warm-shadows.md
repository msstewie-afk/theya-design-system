Editorial type styles and warm Ember shadows. New tokens `typography.display.display-s` (40/44, extrabold, −1px) and `typography.eyebrow.eyebrow-m` (15/20, semibold, 2px) / `eyebrow-s` (13/16, regular, 2px), set in the heading face (Playfair Display in Ember). Utilities: `text-display-s` (with `font-heading`), `text-eyebrow-m`, `text-eyebrow-s` (heading face, uppercase, lining figures included). New profile option `shadow` re-hues the light shadow tint; Ember uses it, so its shadows are warm instead of indigo. New primitive `size.size-minus1`.
