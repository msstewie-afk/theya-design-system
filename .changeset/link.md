New `Link` (`@theya/shadcn/ui/link`) for inline navigation text: text-link colors, underline on hover or always (`underline`, for links in running text), `size` xs–lg for a standalone link or inherited inside text, `inverse` for dark and primary surfaces, `asChild` for router links. Matches the Link component in Figma.
