# Theya для AI-агентов

Три способа дать агенту знания о Theya. Всё генерируется из исходников. Руками ничего не пишем.

## 1. Спецификация компонентов (`packages/theya-shadcn/spec/`)

- `spec/index.json` — список всех компонентов: категория, статус, первое «когда использовать», подсказки «что вместо».
- `spec/components/<name>.json` — полная запись по одному компоненту:
  - строка импорта;
  - guidelines: когда использовать и когда нет (с заменой), анатомия, доступность;
  - пропсы с типами, допустимыми значениями и значениями по умолчанию;
  - пары do/don't в виде TSX;
  - ссылки на сторис.
- `spec/a11y.json` — матрица доступности (WCAG 2.2 AA) по каждому компоненту: сколько сторис проверяет axe в светлой и тёмной теме и какие правила где отключены, есть ли тесты с клавиатурой, учитывается ли reduced motion, правила для высокого контраста, проверки скринридером, принятые отклонения. Собирается `pnpm a11y` из тестов и кода плюс `a11y/manual.json` (то, что проверяется руками). Показывается на Docs-странице компонента в разделе Accessibility и целиком на странице Design System / Accessibility.

Откуда берутся данные:

| Данные | Источник |
|---|---|
| guidelines | `<name>.guidelines.tsx` (файл читается как TypeScript, не исполняется) |
| пропсы | типы компонента, через react-docgen-typescript |
| ссылки на сторис | `title` и экспорты `<name>.stories.tsx` |

```
cd packages/theya-shadcn
pnpm spec          # пересобрать после правок компонентов или guidelines
pnpm spec:check    # падает, если spec/ или llms*.txt устарели (для CI)
```

Изменили компонент, пропсы или guidelines — запустите `pnpm spec` и закоммитьте результат вместе с изменением.

## 2. llms.txt

`public/llms.txt` — индекс в формате llmstxt.org: правила работы с Theya и все компоненты по категориям. `public/llms-full.txt` — все компоненты целиком одним Markdown-файлом.

Storybook отдаёт оба файла:
- `http://localhost:6008/llms.txt`
- `http://localhost:6008/llms-full.txt`

## 3. MCP-сервер (`packages/theya-shadcn/mcp/server.mjs`)

Сервер без зависимостей: работает на чистом `node`, ставить ничего не нужно. Инструменты:

| Инструмент | Что делает |
|---|---|
| `list_components` | все компоненты; фильтр по категории и статусу |
| `search_components` | поиск компонента по задаче словами («confirm a destructive action») |
| `get_component` | полная спецификация одного компонента; можно запросить только нужные части |
| `get_tokens` | семантические токены с алиасами и значениями для светлой и тёмной темы (значения появляются после `pnpm build:tokens`) |

Claude Code подключает сервер сам через `.mcp.json` в корне репо (при первом запуске спросит разрешение). Для других клиентов настройте команду `node packages/theya-shadcn/mcp/server.mjs`, рабочая папка — корень репо.

Проверить сервер вручную:

```
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search_components","arguments":{"query":"pick one of three plans"}}}' | node packages/theya-shadcn/mcp/server.mjs
```
